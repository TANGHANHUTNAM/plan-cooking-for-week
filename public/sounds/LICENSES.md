# New sound set

These files were supplied in this workspace by the project owner after being
crawled from an external source. The original source URL and distribution
license were not included with the files, so authorization should be confirmed
before deploying them publicly.

Current application mapping:

- `ui-press.mp3`: opening button click
- `tick.wav`: reel tick
- `opening.wav`: chest opening
- `reveal-mythical.wav`, `reveal-legendary.wav`, `reveal-ancient.wav`: result reveal by food label
